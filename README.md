# 中美10年期国债利差分析报告

**报告日期：2026年7月25日**


## 一、利差现状概述

截至2026年7月，中美10年期国债利差持续处于深度倒挂状态。

**最新数据：**

- **中国10年期国债收益率**：约1.73%-1.74%，近期在1.73%附近窄幅震荡
- **美国10年期国债收益率**：约4.71%，创2025年1月以来新高
- **中美利差**：倒挂约280个基点（bp）

截至7月10日，中美10年期基准国债利差扩大至280.8bp，较前一周扩大5.5bps。7月9日数据显示，中国10年期国债收益率报1.7376%，美国10年期国债收益率报4.54%，利差倒挂280BPs。

进入7月下旬，随着美债收益率进一步攀升至4.71%，利差倒挂幅度可能已扩大至接近300bp。


## 二、利差倒挂的驱动因素

### （一）美债收益率上行——利差扩大的主要推手

2026年以来，美债收益率持续上行，是中美利差倒挂加深的核心驱动力。主要原因包括：

**1. 通胀黏性与地缘冲突**

美联储6月会议纪要进一步确认通胀黏性，首次将AI投资列为三大通胀风险之一，多位与会者认为年底利率应高于当前区间。与此同时，美伊停火破裂导致地缘冲突升级，推动国际油价上涨，进一步加剧了通胀担忧。布伦特原油重返100美元/桶附近，直接推升了通胀预期。

**2. 美联储政策转向——从降息预期到加息预期**

2026年初以来，市场对美联储的预期从“预防式降息”逐步转向“加息定价”。截至7月24日，联邦基金期货显示美联储7月加息概率已升至38%，一周前仅为12%。2年期美债收益率升至4.37%，创2025年2月以来最高水平。

**3. 沃什改革放大市场波动**

美联储新任主席沃什推行减少前瞻指引的政策改革，让市场更多依赖经济数据判断利率方向，这放大了债市波动。市场已习惯了鲍威尔时代的沟通模式，沃什的理念转变正在制造更大的政策不确定性。

**4. 债务担忧推高风险溢价**

30年期美债收益率连续多日运行于5%上方，逼近2007年以来未曾突破的水平。2026年迄今，30年期美债收益率已有27个交易日高于5%，为2007年以来最多，反映出市场对美国财政状况恶化的担忧。

### （二）中债收益率低位运行——利差倒挂的另一端

与美债收益率持续上行形成鲜明对比的是，中国10年期国债收益率始终在1.7%-1.8%的极低区间运行。

**1. 经济基本面承压**

2026年上半年中国GDP增速4.7%，二季度回落至4.3%，低于市场预期。6月社融同比少增8615亿元，M1与M2剪刀差扩大至4.0%，显示实体经济融资需求不足。经济呈现“生产强、需求弱”的分化特征。

**2. 货币政策适度宽松**

中国央行维持适度宽松的货币政策基调，7月最新LPR报价维持平稳，逆回购基准利率保持不动。央行通过买断式逆回购等工具精准投放中长期流动性。多家机构预计若三季度降息落地，10年期国债收益率可能降至1.5%或以下。

**3. 债市窄幅震荡**

在多空力量平衡下，10年期国债收益率持续围绕1.74%窄幅震荡。政策流动性边际收紧与稳增长政策托底两大力量互相抵消。


## 三、利差倒挂的多维影响

### （一）对汇率的影响：传统框架失效

按照传统的利率平价理论，中美利差深度倒挂理应导致人民币贬值——中国1.75%对比美国约4.5%的收益率，人民币应承受贬值压力。然而，2026年以来人民币对美元已升值逾3%，现实与理论截然相反。

这种“利差走弱、汇率偏强”的组合，意味着**经常账户（尤其是出口）对汇率的权重正在系统性上升**，而金融账户（尤其是利差驱动的证券投资）的边际影响力阶段性下降。2026年出口延续超预期扩张，贸易顺差再创历史新高。此外，自2022年累积至今的待结汇规模已接近1.2万亿美元，对汇率形成持续的流动性支撑。

### （二）对融资市场的影响：人民币融资成本优势凸显

中美利差深度倒挂使得人民币融资成本优势极为突出。2026年以来，中美利差倒挂加剧，推动离岸人民币发行量显著超过中资美元债发行量。

- **熊猫债市场**：存量首超5000亿元
- **离岸人民币债券**：2026年上半年同比增加超三成，美元计价债券则同比减少四成
- **融资成本**：2026年上半年熊猫债平均发行利率为1.83%

### （三）对外资流入的影响：逆势增配中国债市

尽管利差倒挂，境外投资者却逆势增配中国债券：

- 截至2026年4月末，境外机构持有银行间市场债券3.12万亿元
- 境外机构主要持有国债2万亿元，占比72.61%
- 机构预测2026年外资持债规模有望突破4万亿元

吸引外资的原因包括：中国债市持续推进制度型开放（税收优惠、开放国债期货交易等）；中国国债波动较小，成为国际资本“避风港”；以及人民币升值带来的汇率收益。


## 四、后续展望

### （一）美债利率：高波动或成常态

工银国际研报指出，美债市场可能进入**高利率高波动新时期**。主要风险包括：

- 高通胀担忧或将持续，全球货币政策料将步入紧缩周期
- 美国政府债务失控问题难短期解决
- 沃什改革带来政策不确定性

经济学家预计美联储下一步行动仍将是降息，但时间点已推迟至2027年第三季度。与此同时，市场预计美联储基准利率将在2027年6月左右达到约4.23%的峰值。

### （二）中债利率：下行空间有限

当前10年期国债收益率距离强支撑位1.70%空间有限。若降息落地（三季度10BP至20BP），10年期国债收益率可能降至1.5%或以下。但若降息降准未落地，收益率继续下行的空间将有限。

### （三）利差走势：取决于中美货币政策分化

利差走势的核心变量在于中美货币政策的相对走向：
- 若美联储加息而中国降息，利差将进一步走阔
- 若美联储维持利率而中国降息，利差仍将维持深度倒挂
- 若地缘局势缓和、通胀回落，美债收益率回调则利差可能收窄


## 五、总结

2026年7月，中美10年期国债利差倒挂约280个基点，处于历史极深水平。这一局面的形成，既源于美国通胀黏性、地缘冲突和美联储政策转向推升美债收益率，也与中国经济承压、货币政策宽松下中债收益率低位运行密切相关。

值得关注的是，**传统利差分析框架正在失效**——利差深度倒挂并未如理论预期般引发人民币贬值，反而伴随人民币升值；也未阻止外资逆势增配中国债市。这反映出全球宏观格局正在发生结构性变化：贸易顺差对汇率的支撑作用上升、中国债市制度型开放提升吸引力、以及地缘政治因素重塑资本流动格局。
